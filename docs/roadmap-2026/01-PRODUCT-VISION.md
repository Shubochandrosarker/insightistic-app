# Product Vision, Positioning & Principles

## Vision

Make Insightistic the operating system for understanding and improving WordPress visibility across traditional search, AI answers, website health and commercial outcomes.

The product should turn disconnected signals into a prioritized answer:

> **What changed, why does it matter, and what should I do next?**

## Primary target users

### 1. WordPress site owner

Needs a simple health and growth view without learning five specialist tools.

**Core outcomes**
- know if traffic/search is improving
- find technical problems early
- understand which pages need work
- get clear next actions

### 2. WooCommerce operator

Needs to connect site visibility and performance to business outcomes.

**Core outcomes**
- see search-to-revenue relationships
- detect product/landing-page issues
- track revenue, refund, stock and customer trends
- understand whether traffic quality is improving

### 3. WordPress agency

Needs to manage many sites efficiently.

**Core outcomes**
- portfolio health view
- alerts across clients
- scheduled reports
- white-label client reporting
- team roles and client viewers
- fewer manual audits

### 4. SEO consultant / growth marketer

Needs first-party search and technical data in one workspace.

**Core outcomes**
- query/page opportunities
- content decay
- indexability problems
- rank movement
- AI visibility
- technical changes over time

## Positioning

### Recommended category statement

**Search, AI visibility and website intelligence built for WordPress.**

### Supporting statement

Connect WordPress, Google Search Console, Bing, GA4 and Cloudflare. Find what is hurting visibility, see where growth is happening, and know what to fix next.

### What Insightistic is not

- not a global backlink index
- not a generic analytics dashboard
- not a thin AI wrapper
- not a WordPress-only admin plugin with no SaaS intelligence
- not a Screpy copy

## Product moat

The moat is the combined data graph around a website:

```text
WordPress content + configuration
        +
WooCommerce transactions
        +
GSC / Bing search performance
        +
GA4 user behavior
        +
Cloudflare edge traffic / bots / security
        +
technical crawl state
        +
performance history
        +
AI visibility observations
        =
prioritized business-impact intelligence
```

Most tools specialize in only one or two of these layers.

## Product principles

### 1. Evidence before AI

AI explains data; it does not invent data. Every recommendation should be traceable to evidence.

### 2. First-party data first

Prefer GSC, Bing, GA4, WordPress, WooCommerce and Cloudflare over expensive estimates where possible.

### 3. Actionability over vanity metrics

Do not merely show "371 issues." Rank issues by impact, affected high-value pages, trend and fixability.

### 4. Progressive complexity

Overview is simple. Deep screens expose full tables and filters for expert users.

### 5. Agency scalable by design

Every feature must consider 1 site and 100 sites from the beginning.

### 6. Cost-aware architecture

AI, SERP checks and high-frequency crawling have explicit budgets. Free/LTD usage cannot create unlimited variable cost.

### 7. WordPress-native execution advantage

Where safe and reversible, Insightistic should eventually recommend or apply WordPress-specific fixes rather than only describe them.

## North-star product metrics

- weekly active organizations
- monitored sites with fresh data
- percentage of sites with at least three connected data sources
- issues resolved per active site per month
- insights actioned / saved
- automated reports delivered
- renewal rate
- agency site expansion
- percentage of users who reach "first useful insight" during onboarding

## First-value target

A new user should receive useful information within **10 minutes** of signup, even before all historical data is ready.

Recommended onboarding order:

1. create account
2. add project/site
3. connect WordPress plugin
4. connect GSC
5. run initial lightweight crawl
6. show first health/search overview
7. optionally connect Cloudflare + GA4 + Bing
8. begin deeper backfills in background
