# Repository Audit — 2026-08-15

Scope: full-repository security/correctness sweep of both `insightistic-api`
(Laravel) and `insightistic-app` (Next.js), plus a deploy-readiness check,
run after the P0-P11 roadmap phases merged. Three independent sweeps —
backend security, frontend security, deploy readiness — each ran against
the merged `main`, followed by triage of the 9 open Dependabot PRs.

This is a point-in-time audit, not a standing document — treat findings
below as either fixed (see `CHANGELOG.md`'s "Security — deep repository
audit" entry for exact commits) or explicitly deferred with a reason.

## Fixed

See `CHANGELOG.md` → `[Unreleased]` → "Security — deep repository audit
(P0-P11 hardening)" for the full list with file-level detail. Summary:

1. Missing role gates on mutating Automation Studio / Bridgistic
   approve-reject / Anomaly acknowledge / Alert resolve-reopen / Report
   Schedule CRUD endpoints — a `client_viewer` could trigger real side
   effects (webhooks, emails, executed actions).
2. `PluginAiController` bypassed `allow_external_ai` org consent.
3. `CopilotController::feedback()` didn't verify thread ownership.
4. `nanoid` (high) and `vitest` (critical, dev-only) npm vulnerabilities.
5. Unvalidated `href` schemes on 4 API-sourced link sites (frontend).
6. QR-code `dangerouslySetInnerHTML` → safe data-URI `<img>`.
7. Closed a regression-risk Dependabot PR (Docker PHP 8.4→8.5) instead of
   merging it; merged the rest of the backlog.

## Deferred — tracked, not fixed in this pass

These were surfaced by the audit but deliberately left alone. Re-evaluate
before the next audit pass, or sooner if the underlying code changes.

### Frontend has no consumer for the P0-P11 backend work (High — scope gap, not a vulnerability)

Confirmed via git history and route/consumer search: none of the P0-P11
backend endpoints (`/metrics`, `/agency/overview`,
`/sites/{id}/analytics/query`, `/sites/{id}/evidence`, `/sites/{id}/ask`,
`/sites/{id}/saved-insights`, `/sites/{id}/automation-rules`,
`/sites/{id}/anomalies`, `/sites/{id}/investigations`,
`/sites/{id}/action-proposals`, `/sites/{id}/outcome-verifications`) are
called from anywhere in `insightistic-app`. The frontend instead calls an
older, parallel set of endpoints (`/copilot/*`, `/sites/{id}/insights/*`,
`/sites/{id}/alerts/*`, `/sites/{id}/intelligence/*`) that predate this
work. There is no Ask Insightistic V2 UI, no Automation Studio UI, no
Anomaly Engine UI, no WPAgentistic Investigations UI, no Bridgistic
approve/reject UI, and no Agency Intelligence UI.

**This is not something this audit pass fixes** — it's a product-scope
decision (build the missing UI, or treat P0-P11 as a backend-only/API-only
release for now) that needs a human call, not a unilateral implementation.
Flagging it here so it isn't mistaken for "shipped and usable" by a future
reader of the CHANGELOG.

### Frontend CSP still needs `script-src 'unsafe-inline'` (Low, already tracked)

`next.config.mjs` already carries a comment acknowledging this is required
by Next's hydration scripts + the inline theme-flash script, with a
follow-up to move to nonces via middleware. Not re-litigated here — no new
information since that comment was written.

### `x-ins-csrf` header set ad hoc in one place (Low)

`app/dashboard/copilot/page.tsx`'s hand-rolled SSE `fetch()` call sets
`x-ins-csrf: 1`; the shared `lib/api.ts` client every other mutating call
goes through does not. Given the app authenticates via a Bearer token (not
an ambient cookie), classic CSRF isn't exploitable either way, so this is
most likely dead code — worth removing or centralizing next time
`lib/api.ts` is touched, not urgent enough to change unrelated to that.

### Unused `sharp` override in `package.json` (Low, cosmetic)

`next.config.mjs` sets `images: { unoptimized: true }` specifically to
keep `sharp` out of the request path, but `package.json` still pins a
`sharp` version via `overrides`. `npm ls` shows it as `extraneous`. Safe to
remove; left alone here since it's zero-risk and not worth the review
churn as part of a security-fix diff.
